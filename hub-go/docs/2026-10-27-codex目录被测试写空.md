# 2026-10-27 Codex 间歇性打不开：`~/.codex/aihub-model-catalog.json` 被 go test 写成空表

> 现象：Codex 桌面版启动弹窗
> `model_catalog_json path /home/<user>/.codex/aihub-model-catalog.json must contain at least one model`，
> 用户描述「时不时」出现。诊断来自另一个 dsh 会话（2026-10-27），修复在本仓库。

## 1. 根因（两个缺陷叠加）

**缺陷 1：`homeJoin` 恒用真实 `$HOME`，无视 `hubRoot`**

`client_takeover.go:33` 原来直接 `os.UserHomeDir()`，而测试只把 `hubRoot` 换成
`t.TempDir()`——那条路径归 `dataPath()` 管（agg_models.json / 日志 / state.json），
管不到 `~/.codex/...`。于是测试里调 `writeCodexCatalogFile` 写的仍是用户真实文件。

**缺陷 2：测试故意用空白名单，还断言「空表也要写出去」**

`codex_catalog_display_test.go:96 TestCodexCatalogFileLocation` 把 `aggList` 清空后调用
真实写盘路径，断言「空白名单也应能写出目录」，且 cleanup 只还原 `aggList`/`hubRoot`，
不还原被覆盖的用户文件。

**为什么是「时不时」**：同文件里 `TestCodexCatalogFileDisplay`（非空假数据）与
`TestCodexCatalogFileLocation`（空表）都写同一个真实文件，`go test` 按函数名字典序执行，
后者最后落盘 → 空表。用户每跑一次 `go test`（哪怕验证无关改动）就把 Codex 目录打回空表；
Codex 桌面版只在启动时读一次、不会自愈，于是「下次打开就报错」。

时间线印证：`trae_stream_test.go` 修改于 12:20:39，真实 catalog 被写空于 12:22。

## 2. 修复

| 文件 | 改动 |
|---|---|
| `client_takeover.go` | 新增 `var userHomeDir = os.UserHomeDir`，`homeJoin` 改用它 → 测试可注入临时 home |
| `codex_catalog.go` | ①`entries == 0` 时**拒绝写盘**：记 `⚠ 桌面版目录跳过…` 日志并返回错误，保留现有文件；②覆盖已有文件成功后记一行 `桌面版目录已刷新：N 个模型 → 路径`（原来成功时完全静默，12:22 那次写空在 hub.log 里查不到痕迹）；③写之前 `MkdirAll` 父目录（全新机器没有 `~/.codex` 时不再 ENOENT） |
| `codex_catalog_display_test.go` | 新增 `isolateUserHome(t)` 把 `userHomeDir` 指到 `t.TempDir()`，两个写盘测试都先调用；`TestCodexCatalogFileLocation` 改用非空白名单并断言落盘路径 = `<home>/.codex/<catalog>`、`.tmp` 已清理、JSON 里有 2 条；新增 `TestCodexCatalogSkipsEmptyWhitelist`：已有文件 + 空白名单 → 返回错误、内容与 mtime 不变、不产生 `.tmp` |
| `proxy_agg.go` | 新增 `aggOpenAIModelCount()`：`data` 是 Go 原生 `[]map[string]any`，而 `asSlice` 只认 JSON 解析的 `[]any`，断言必失败 → 日志恒报「0 个模型」（实测 curl 拿到 14 条、日志同时写 0，排查时被带偏过）。现按类型分别计数 |
| `proxy_agg_models_log_test.go` | 新增：原生 `[]map[string]any`→3、`[]any`→2、空/缺字段/类型错→0 不 panic |

## 3. 验收

```bash
cd /home/<user>/opt/AI_test/hub-go/hub-go
H1=$(sha256sum ~/.codex/aihub-model-catalog.json | cut -d' ' -f1)
/usr/local/go/bin/go test ./... -count=1
H2=$(sha256sum ~/.codex/aihub-model-catalog.json | cut -d' ' -f1)
[ "$H1" = "$H2" ] && echo "✅ 测试隔离生效，真实文件未被修改"
```

- 全量测试跑完 `~/.codex/aihub-model-catalog.json`、`~/.codex/config.toml`、
  `~/.claude/settings.json` 的 sha256 与文件数均不变；
- 空白名单不落盘由 `TestCodexCatalogSkipsEmptyWhitelist` 钉住；
- `/v1/models` 日志条数与 curl 一致（`aggOpenAIModelCount` 单测钉住）。
